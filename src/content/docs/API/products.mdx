### api.transcendbinary.co.uk/products.json
## Overview

Our Products API lets you fetch a complete, categorised list of our products and associated metadata
```json
{
    "Hoodies": {
        "products": [
            {
            "name": "TB Logo Hoodie",
            "image": "https://mockup-api.teespring.com/v3/image/lltWB2B2JzT9NzzcpW5dpyoa8Ug/800/800.jpg",
            "price": {
                "USD": 40.0,
                "GBP": 40.0,
                "EUR": 50.0
            },
            "url": "https://shaunclarke.creator-spring.com/listing/new-tb-logo-hoodie"
            }
        ]
    }
}
```
The root object contains a property (in this case, "Hoodies") which is the product category.  
contained within, is a "products" array containing the following properties:  
<ul>
<li><code>name</code> - The name of the product</li>
<li><code>image</code> - A link to the main product image</li>
<li><code>price</code> - An object containing the price of the product in various currencies</li>
<li><code>url</code> - A link to the product page</li>
</ul>
