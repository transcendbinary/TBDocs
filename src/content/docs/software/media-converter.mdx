Media Converter is a software application which allows you to convert media files from one format to another. It supports a wide range of formats and codecs, and can be used to convert audio, video, and image files.

## Usage

Paste a file path into the input box, or click the "Browse" button to select a file from your computer.  
The Dropdown menu below will populate with available formats to convert to, Select a format.
By default, the path and filename for the output will match the input; i.e. the converted file will be saved in the same location as the input file with the same name.
you can manually change the path and filename using the text box or by clicking the "Browse" button next to the output box.

## Supported Formats

| Image Formats | Video Formats | Audio Formats |
|:---|:---|:---|
| jpg | mp4 | mp3 |
| png | mkv | wav |
| gif | avi | flac |
| bmp | mov | aac |
| tiff | flv | ogg |
| webp | webm | wma |
| heif | wmv | m4a |
| ico | mpg | opus |
| | mpeg | alac |
| | ogv | aiff |
| | 3gp | caf |
| | m4v | |

please note: .jpeg is accepted as an input format, but will be converted to .jpg on output.

## Advanced Options

Currently, Media Converter does not have the ability to use custom codecs, timestamps, scale, etc. However, this is planned for a future update.
