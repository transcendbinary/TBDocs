---
title: EoL Software
description: Software which is no longer supported by Transcend Binary
---
EoL software is software which is no longer supported by Transcend Binary. This means software is no longer in active development: updates for EoL software are managed as follows:

- Feature updates: Extremely rare; open source contributions may be accepted and merged, in which case a new version may be released.
- Bug Fixes: Not likely, but we'll try to keep software functional where possible.
- Security Updates: Likely to be released as long as source code is available and software runs on supported platforms.

Operating systems and frameworks which are no longer supported by their developers may not have security updates released due to the possibility of vunerabilities out of our control.

You can find a list of EoL software on our [EoL Software page](https://transcendbinary.co.uk/gamesApps/eol/).
