## Installation

- Download the required files
	- Save `square.png` to either your Photos library or the Files app.
	- Open `TB App.shortcut` and tap **Add Shortcut** when prompted.
- Locate the shortcut in the Shortcuts app and tap the **meatball menu (•••)** to open its editor.
- Add the Shortcut to your Home Screen
	- Tap the downward arrow at the top of the shortcut editor.
	- Select **Add to Home Screen**.
	- Tap the icon placeholder on the left-hand side.
- Set the app icon
	- Choose **Choose Photo** or **Choose File**, depending on where you saved `square.png`.
	- Locate and select the saved image.
	- Tap **Add** in the top-right corner.
	- Position the new icon on your Home Screen.

The app should now be accessible directly from your Home Screen.

**Note:** Adding the Shortcut to your Home Screen does not add it to the iOS App Library.

## Updates

We recommend checking for updates every 1–2 weeks to ensure you have the latest features and bug fixes.

### Checking for updates

1. Open the Transcend Binary app.
2. Select **See More**.
3. Select **Check for Updates**.

The update checker will display your currently installed version alongside the latest available version.

### Installing an update

If a newer version is available:

1. Select **Update** on the next screen.
2. Download the latest version from the Transcend Binary website.
3. Open the Shortcuts app and locate the existing Transcend Binary shortcut.
4. Long-press the shortcut and select **Delete**.
5. Install the newly downloaded version by following the [installation instructions](#installation) above.

You'll need to repeat the Home Screen setup to install the updated shortcut.
