Our CLI app is developed in .NET and supports every desktop platform.

## Installation

use the [installation guide](https://github.com/transcendbinary/TBAppConsole/blob/master/readme.md) on github to build from source

## Usage

Please Note: The app will clear the terminal. please ensure there is no important information in your terminal before running.  
Upon Loading the app, It will check for updates automatically and prompt you to update. Note; if you clone from source, decline this update and clone build manually.  

Use number keys to select menu options or press esc to quit the app. These actions are instant and do not require pressing enter.

### Menu Options
#### Main Menu

| Option | Description |
|---|---|
| **1. See Latest Blog Post** | Print latest blog post to the terminal. |
| **2. Visit Website** | Open the Transcend Binary website in your default browser. |
| **3. Contact Support** | Get in touch with our support team. |
| **4. Check Status of Services** | View the current status of Transcend Binary services. |
| **5. About** | View information about the application. |

Please note: Web links in a linux TTY will open in a CLI web browser such an lynx, but this causes the shell to break; In any WM/DE session, it will open in your default browser, but the terminal used will be handed over to the browser and will not automatically return. These are known issues and are being looked into.

#### Support menu

Currently only supported option is email. visit https://transcendbinary.co.uk/contact/ for more support options.

#### Status Menu

choose a service to check the status of that service. or choose "Full Test" to check every service in order.
