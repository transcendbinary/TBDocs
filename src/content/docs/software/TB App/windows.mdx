## Menu Strip

### Store

Contains links to our various stores

### Web Tools

Most links used within web views will open in your systems default browser with the exception of the games and apps page which is designed to be navigated within the web view

#### Clear

- **Clear Cache**: Clear WebView2 Cached content such as images, styling and text content; Use this when pages are missing content
- **Clear Browsing Data**: Clear Misc. browsing data generated by web traffic

#### Refresh

- **Soft Refresh**: Refresh the current URL of the active tab; use this to fetch new content
- **Hard Refresh**: Reset every tab to their default locations; use this when a web view navigation doesnt fail over to your default browser

## Main Tabs

| Tab | Description |
|---|---|
| **Home** | Home page, shows MOTD and app updates/known issues |
| **News** | Shows the 5 most recent blog posts and a button to visit our blog archive. |
| **Latest Products** | Shows our most recently released products |
| **Games & Apps** | Browse and Download our games and apps natively without the need for a browser |
| **Support** | Contact our support team & get help with various issues |
| **Chat with Miles** | Talk to our support chatbot to get quick answers to common questions |
| **Status** | Check the status of our services |

## Check for Updates
Help > Check for Updates - This shows your currently installed version. Clicking "check for updates" in this window will check the server for new versions. if one is found, youll be prompted to download it. This will download the latest version of the app. Ensure the app is closed before running the new installer, youll be prompted to remove the old version.
